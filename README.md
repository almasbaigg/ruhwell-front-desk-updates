# Ruhwell Front Desk

Desktop app for Ruhwell Med: reads the day's visits from RxNT and texts patients through RingRx (review requests, reminders, welcome and reschedule messages, schedule alerts). Patient data stays on the computer.

Downloads are on the [Releases](../../releases) page:
- **Windows:** `RuhwellFrontDesk.exe`
- **Mac:** `RuhwellFrontDesk-arm64.dmg` (Apple Silicon) or `RuhwellFrontDesk-x64.dmg` (Intel)
